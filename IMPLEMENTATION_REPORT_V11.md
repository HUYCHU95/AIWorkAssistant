## Delivered
- Existing ASP.NET Core 10 MVC + EF Core SQLite architecture retained. Grouped responsive sidebar, Home dashboard, AI Workspace, Work Management, Planning & Reports and Settings. No npm/CDN runtime dependency.
- SQLite Light/Dark/System theme, independent group accents, validated per-controller accents, unified accent and configurable chat send key.
- Dashboard APIs query actual SQLite records: eight KPI cards, actual/planned progress with null for insufficient planning data, separate Unknown health, date timeline and stored dependency relationships, searchable/sortable/grouped/paged task grid. Inline writes enforce CSRF, enum/date limits, optimistic version and audit. Progress is task-count completion, not invented physical/manpower KPI. Baseline and current target stay separate.
- Optional local licensed DevExtreme adapter for dxChart, dxPieChart and dxDataGrid. Standard components are active until assets/license are supplied. Licensed branch has not been runtime-tested; see DEVEXTREME_SETUP.md.
- AI entry on Project, Workstream, Task, Issue/Commitment/Instruction/Decision, Inbox, Source and Memory forms plus a standalone Analysis page. Multiple file chooser, drag/drop, clipboard images, previews/removal, dedup by source + SHA256, persisted originals and download checksums. Chat supports the same bounded attachment formats.
- Local TXT UTF-8, PDF text (PdfPig), DOCX text/tables and XLSX values/tables (ClosedXML). No macro/formula execution. Vision image data URLs, PDF input_file and up to three supported Word embedded images go to the real Responses endpoint only when global permission and non-confidential source permission both allow it.
- Strict structured analysis produces editable fields and source-quoted suggestions. Dates from source become Suggested; no silent committed deadline/status/PIC/completion overwrite. Candidate IDs validated locally, ambiguity/conflicting target dates warned. Form writes preserve SourceLinks. Bulk items create actual PendingApproval/NeedsReview receipts; model cannot approve. Duplicate existing tasks/projects/streams link source instead of creating again. Approval checks duplicate task context again.
- Reviewed create_project/create_workstream/create_decision actions added with validation, receipts, audit, source links and safe compensating undo. Existing task/action workflows retained.
- Chat fetch + SSE without page reload; provider output_text.delta forwarded while streaming. User acknowledgement follows persistence. Unique request IDs prevent duplicate turns; same ID replays persisted state rather than executing again. Tool results remain separate from model text. Stop/cancel/timeout retains partial text with honest status. Reconnect retry uses same request ID; a fresh AI attempt after a terminal failed/cancelled turn is an explicit new message.
- Enter sends; Ctrl+Enter and Shift+Enter add newline in default mode. CtrlEnter send mode available. Composition guards prevent Enter sending during IME composition. Safe DOM-only Markdown renderer supports headings, lists, inline code/bold/links, code copy and tables; no raw HTML evaluation. Source links persist with attached chat turns.
- Start.bat chooses side-by-side V1.1 through Start-V11.ps1. It refuses to transfer while the old app holds its lock, stages/copies existing Data/config only once, preserves originals and uses the existing pre-migration backup/probe. It never kills the user's app. Root launcher transfer tested twice on a synthetic fixture. New self-contained publish: publish/AIWorkAssistant-1.1.
